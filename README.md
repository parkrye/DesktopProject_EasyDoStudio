# EasyDoStudio

OBS 대신 쓰려고 만든 Windows 화면 녹화 · 편집 프로그램. 원하는 화면만 골라 녹화하고, 소스별로 볼륨을 따로 잡고, 녹화한 영상을 바로 잘라 붙이고 자막까지 넣어 내보낸다.

## 기능

| 영역 | 내용 |
|---|---|
| 녹화 소스 | 모니터 전체 · 특정 창 · 드래그로 고른 화면 영역 · 웹캠 · 이미지(PNG 투명도) · 텍스트(글꼴 · 색 · 외곽선 · 배경 상자), 화면 소스마다 마우스 커서 보이기 / 숨기기 |
| 화면 구성 | 장면 여러 개, 소스 겹치기 · 순서 · 표시/숨김, 미리보기에서 끌어 옮기기 · 모서리로 크기 조절(가장자리 · 가운데 자석 정렬) |
| 오디오 | 마이크 · 스피커 출력 · **특정 앱 소리만**, 소스별 볼륨 · 음소거 · 레벨 미터, 기본 장치가 바뀌면 자동으로 다시 연결 |
| 녹화 | mkv / mp4, 해상도 · fps · 비트레이트 설정, NVENC · AMF · QSV 하드웨어 인코더 자동 감지(없으면 x264), **오디오를 소스별 트랙으로 나눠 저장**, 일시정지 |
| 편의 | 전역 단축키(게임 중에도 동작), 트레이 아이콘(녹화 상태 색상, 메뉴로 녹화 · 일시정지), 장면 · 설정 자동 저장 |
| 편집기 | 썸네일 · 파형 타임라인, 자르기 · 구간 삭제 · 순서 바꾸기 · 되돌리기, **구간별 재생 속도(0.25~4배) · 페이드 인/아웃 · 볼륨**, 여러 파일 이어붙이기, 트랙별 볼륨을 다시 섞기, mp4 / mkv 내보내기 |
| 자막 | 음성 인식(Whisper)으로 자동 생성, 직접 추가 · 수정 · 시간 맞추기, 긴 문장 자동 줄바꿈 · 나누기, 글꼴 · 크기 · 색 · 위치 · 배경 상자 스타일, 영상에 입히기 또는 .srt 저장 |

## 받아서 바로 쓰기

[**Releases**](../../releases/latest)에 exe 두 개가 붙어 있다. 하나만 받으면 된다.

| 파일 | 크기 | 조건 |
|---|---|---|
| `EasyDoStudio-standalone.exe` | 약 78MB | **.NET 설치 없이 바로 실행된다.** 남한테 줄 거면 이걸 준다 |
| `EasyDoStudio.exe` | 약 28MB | [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0)이 깔려 있어야 한다 |

### 같이 필요한 것

- **Windows 10 2004 이상** (Windows 11 권장. 녹화 중 노란 캡처 테두리 없애기, 앱별 소리 녹음은 Windows 10 21H2 이상)
- **FFmpeg** — 녹화 · 편집 · 자막 생성에 쓴다. 명령 프롬프트에서 한 번만 설치하면 된다.

  ```
  winget install Gyan.FFmpeg
  ```

  설치하면 프로그램이 알아서 찾는다. 다른 곳에 둔 ffmpeg를 쓰려면 설정 → FFmpeg에서 경로를 지정한다.

### 처음 켜면

1. 데스크톱 오디오와 마이크가 믹서에 자동으로 들어온다.
2. 소스 `+`에서 녹화할 모니터 · 창 · 영역을 고른다.
3. **녹화 시작**(또는 `Ctrl+Shift+F9`). 다시 누르면 저장된다.
4. **편집기**에서 방금 녹화한 파일을 열어 자르고, 자막을 넣고, 내보낸다.

## 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+Shift+F9` | 녹화 시작 / 중지 (어디서나, 설정에서 변경) |
| `Ctrl+Shift+F10` | 일시정지 / 계속 (어디서나, 설정에서 변경) |
| 미리보기에서 드래그 | 소스 이동 · 크기 조절 (Shift: 비율 무시, Alt: 자석 정렬 끄기, 방향키: 1px 이동) |
| 편집기 `Space` / `S` / `Delete` | 재생 · 정지 / 재생 위치에서 자르기 / 구간 삭제 |
| 편집기 `Alt+←` `Alt+→` | 선택한 구간을 앞 · 뒤로 |
| 편집기 `E` | 선택한 구간의 효과 (속도 · 페이드 · 볼륨) |
| 편집기 `T` / `[` / `]` | 자막 추가 / 자막 시작 · 끝을 재생 위치로 |
| 편집기 `Ctrl+Z` / `Ctrl+Y` / `Ctrl+S` | 되돌리기 / 다시하기 / 자막 저장 |

## 저장 위치

| 무엇 | 어디 |
|---|---|
| 녹화 파일 | `동영상\EasyDoStudio\` (설정에서 변경) |
| 장면 · 소스 · 설정 | `%AppData%\EasyDoStudio\project.json` |
| 자막 | 영상과 같은 폴더, 같은 이름의 `.srt` |
| 자막 생성 모델 | `%LocalAppData%\EasyDoStudio\models\` |

## 개인정보

- 계정 · 광고 · 사용 통계 · 오류 보고 없음. 녹화 · 편집한 영상은 내 PC 밖으로 나가지 않는다.
- 인터넷을 쓰는 곳은 **자막 자동 생성을 처음 쓸 때 음성 인식 모델(약 550MB)을 받는 것 하나**다. Hugging Face의 [whisper.cpp 모델 저장소](https://huggingface.co/ggerganov/whisper.cpp)에서 받는다. 받아쓰기 자체는 내 PC에서 한다.
